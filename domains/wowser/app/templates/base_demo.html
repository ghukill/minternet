<base> Tag Demo

This page sets <base href="{{ public_base_url }}/static/">

All relative URLs are now resolved against this base, not the page URL!

How Base Tags Work

The <base> element specifies the base URL for all relative URLs in a document.

Without Base Tag

  • href="style.css" → /base-demo/style.css
  • href="images/photo.jpg" → /base-demo/images/photo.jpg

With Base Tag (this page)

  • href="style.css" → {{ public_base_url }}/static/style.css
  • href="images/photo.jpg" → {{ public_base_url }}/static/images/photo.jpg

Why This Breaks Archives

  • Archive URL rewriting must account for the base tag
  • The base URL may be an absolute URL (like on this page)
  • Replay systems must rewrite the base tag itself
  • Some tools miss this and fail to load resources

Test Links

These links use the base URL for resolution:

  • Relative: test.html (resolves to /static/test.html)
  • Parent: ../ (resolves to /)
  • Absolute: Full URL (unchanged)
