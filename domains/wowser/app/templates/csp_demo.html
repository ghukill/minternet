Content Security Policy Demo

CSP Header Active

This page is served with a restrictive Content-Security-Policy header:

default-src 'self'; script-src 'self'; style-src 'self'

What's Broken?

Inline Styles

This text should be red if inline styles worked. (They won't!)

The <style> block in the head is blocked by style-src 'self'

Inline Scripts

This text was NOT modified by an inline script.

The inline <script> above is blocked by script-src 'self'

Event Handlers

Inline event handlers are also blocked by the CSP.

Why This Matters for Archives

  • Web archive replay systems inject JavaScript (like wombat.js)
  • These scripts intercept and rewrite URLs
  • Strict CSP headers can block the replay scripts!
  • Archives may need to strip or modify CSP headers

Archive Solutions

  • Remove CSP headers during replay
  • Modify CSP to allow archive scripts
  • Add nonces or hashes for archive scripts
  • Document which sites have problematic CSP
