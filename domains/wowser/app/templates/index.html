WOWSER

The Museum of Strange Websites

Welcome to Wowser, a collection of intentionally pathological web patterns that challenge web archiving and replay systems.

These patterns represent real-world edge cases that can break web archives. Use them to understand replay limitations.

Web Archiving Notes

Each exhibit demonstrates a specific challenge for web archiving:

  • SPAs: Content isn't in initial HTML response
  • Base tags: URL rewriting becomes complex
  • Random URLs: Crawlers can't reach a fixed endpoint
  • Inline assets: Usually work well, but can be huge
  • CSP: May block archive's injected rewriting scripts
  • WebSockets: Cannot be archived/replayed meaningfully
  • Shadow DOM: Content may not be visible to capture tools
