Why This Works Well for Archives

  • No external requests needed during capture
  • All assets included in single HTML file
  • No URL rewriting required for these assets

Why This Can Be Problematic

  • Base64 encoding increases size by ~33%
  • Can't be cached separately from HTML
  • Large assets make HTML file huge
  • Can slow down parsing
