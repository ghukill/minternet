Why This Is Problematic

  • Every page response contains new, unique URLs
  • There's no way to know when you've "finished" crawling
  • A naive crawler will follow links forever
  • Similar patterns exist on real sites (session IDs, tokens, etc.)

Solutions for Crawlers

  • Set a maximum crawl depth
  • Use URL pattern matching to detect traps
  • Limit pages per path prefix
  • Use scope definitions (e.g., "only /blog/* paths")
