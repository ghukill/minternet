Why This Is Problematic

  • <meta http-equiv="refresh"> causes automatic redirects
  • Crawlers must decide whether to follow these
  • Some sites use this for infinite loops
  • Can cause crawlers to get stuck

How Crawlers Handle This

  • Set maximum redirect depth
  • Track redirect chains
  • Detect loops via URL patterns
  • Timeout on excessive redirects
