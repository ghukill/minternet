Why WebSockets Can't Be Archived

  • WebSockets are persistent, bidirectional connections
  • They're stateful and real-time
  • Content depends on server-side state
  • No way to "replay" an interactive connection

What Archives Can Do

  • Capture the initial HTML/JS that sets up the connection
  • Stub out WebSocket to return mock data
  • Show error message explaining limitation
  • Capture HTTP fallback if site has one
